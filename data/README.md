# Data (generated; never committed)

Everything under `data/` is downloaded or generated by the setup and `prepare` commands in the
README. Only this file is tracked.

| Folder | Created by | Contents |
|---|---|---|
| `data/fcct/` | `scripts/setup_fcct.py`, `fcct.py prepare` | Paper PDF, original POPE files, COCO val2014 instances, COCO images (tracing, POPE, R-FCCT calibration, CHAIR), `trace.jsonl` (1,371 present-object questions, 500 images), `pope.jsonl` (9,000 questions, 500 disjoint images), checksum locks |
| `data/rfcct/` | `rfcct.py prepare` | `contrastive_trace.jsonl` (present + absent objects on the tracing images), `calibration.jsonl` (200 new images, 1,200 questions), `test_pope.jsonl`, `data_card.json` |
| `data/bench/` | `scripts/setup_bench.py`, `bench.py prepare` | MME parquet and extracted images, OPERA `chair.py` + COCO 2014 caption/instance annotations, MMHal-Bench template/images/judge script, manifests `pope/mme/chair/mmhal.jsonl`, `sources/bench.lock.json` |

Tracing, R-FCCT calibration and POPE test images are disjoint (checked). CHAIR images exclude the
tracing and calibration images; they may coincide with POPE images, which is a different task.
The tracing subset (seed 17) is an independent selection, not the unavailable author subset.

upstream revisions. Do not commit downloaded images,
